# 🚀 Quizify AR: Advanced Assessment Platform

A high-end, professional quiz application built with modern web technologies. Quizify AR focuses on advanced DOM manipulation, responsive design, and cutting-edge UI/UX principles to deliver a seamless assessment experience.

## ✨ Key Features

### 🎨 Advanced UI/UX
- **Dynamic Mesh Background**: An immersive, animated background featuring multi-layered radial gradients and floating elements.
- **Glassmorphism Design**: Modern frosted-glass aesthetic using advanced CSS `backdrop-filter` and subtle border treatments.
- **Responsive Architecture**: Fully optimized for all devices, from large desktop monitors to mobile smartphones.

### ⚙️ Core Functionality
- **Dynamic DOM Manipulation**: Seamless transitions between Start, Quiz, and Result screens without page reloads.
- **Real-time Progress Tracking**: A visual progress bar that updates as the user moves through the assessment.
- **Interactive Scoring**: An animated SVG circular progress indicator and a counting score number on the results screen.
- **Mandatory Validation**: Built-in logic to ensure users select an answer before proceeding, maintaining data integrity.

### 🧠 Content
- **10 Tech-Focused Questions**: Covering topics from Cloud Computing and AI to Web Development basics (HTML, CSS, JS).
- **Personalized Results**: Dynamic feedback messages and icons based on the user's performance percentage.

## 🛠️ Technologies Used

*It is a Frontend project using :-*
- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Advanced animations, Flexbox/Grid layouts, and CSS variables for theming.
- **JavaScript (ES6+)**: Core logic, state management, and DOM manipulation.
- **Google Fonts**: "Inter" typeface for professional typography.

## 🚀 Getting Started

1. **Clone or Download**: Save the project files (`index.html`, `style.css`, `script.js`) to your local machine.
2. **Open**: Simply double-click the `index.html` file to launch the application in any modern web browser (Chrome, Firefox, Edge, or Safari).
3. **No Dependencies**: This is a pure vanilla project—no external libraries or frameworks are required to run it.
